Local findings and proposed change

fast_model.build_fast_payload and fast_codex.build_codex_packet already project compact controller state. Neither resends an entire interaction history. fast_policy bounds controller memory to 240 characters and preserves only the previous action/result plus current proprioception, phase and retry count. The old model.py still has bounded recent_text_history; it is not the fast path.

The missing reusable component is reviewed experience selection. Add a deterministic, bounded lookup of brief historical lessons by current phase and explicit result flags. Select at most two cards; do not use image processing, object positions, historical joint targets, movement directions, model reasoning history, or extra model calls. Label all cards as historical advice. Their text may guide Astra's current visual judgment but cannot establish current contact, clearance, grasp, success, phase transition, permission or execution eligibility.

Cards must cite immutable local evidence hashes. Reports containing human side guidance remain human-assisted evidence; they are not autonomous visual proof. A claimed failure cause remains unverified when the original report says so. No card grants permission to replay a command after an uncertain send, modify limits, or change timeout/hold behavior.

Improvement protocol for later rounds: preserve a baseline -> isolate one trace-linked prompt/memory/routing change -> offline contract/replay tests -> independent review -> evaluate matched new trials under an unchanged task and safety contract -> promote only from measured evidence. Keep infrastructure failures distinct from task failures. No runtime self-modifying executable code is introduced here. Current benchmark gains are unknown until new controlled trials; no speedup or success-rate claim is made.

Implemented: right_pick.fast_experience and source-pinned reviewed_experiences.json; both fast_model and fast_codex attach the same bounded historical_advisories field beside, not inside, controller_state. The selection uses task/phase or generic skill/operation aliases and explicit result flags. No raw arbitrary memory is searched. Missing, changed or out-of-bundle evidence excludes a card; changed deck bytes exclude the deck until its source pin is explicitly reviewed and updated. Standalone installed code without the evidence bundle runs without cards. No runtime promotion or code execution is added. The prompt includes the deck and evidence hashes for the existing local input audit.

The final deck has eight short lessons drawn from the pen reports, the timeout incident, and the newly copied can/charger outcome reports. It preserves the difference between grasp success and insertion success, actual object-axis and tool-axis alignment, bounded recovery after no progress, view changes without budget reset, and post-release independent support. Can evidence reports long elapsed time but does not substantiate a detailed repeated-historical-angle causal narrative, so that claim was not added. These are static reviewed hints, not a reproduction of an interaction-memory learner or online self-evolution system.
