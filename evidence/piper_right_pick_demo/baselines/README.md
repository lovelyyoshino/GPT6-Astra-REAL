# 右臂实机实验基线

保留两种不同的任务决策方式，供后续实验比较。两个归档样本都没有完成闭爪抓取；应比较各自实际完成的阶段，不能把计划中的后续动作算作已执行。

| 基线 | 谁生成任务动作和目标 | 逆解与下发 | 已有实机证据 |
| --- | --- | --- | --- |
| [精细程序控制 right_pick](right_pick/README.md) | 视觉几何、预设抓放逻辑和轨迹程序 | SciPy 数值逆解、厂家 FK 核对、SDK `JointCtrl` | 103 个计划运动段，发送 60 段，59 段确认到位，尚未闭爪 |
| [模型直接规划 model_direct_vendor_ik](model_direct_vendor_ik/README.md) | 模型阅读画面与状态，直接给出阶段及六维末端目标；执行器读取参数表 | SDK `EndPoseCtrl` 把目标交给厂家控制器求解和执行 | 展开、张爪、转向完成；接近未到位，超时停止后发生危险下落，尚未闭爪 |

第二种方式的研究价值在于：任务变化首先改变模型给出的动作数据，固定的设备工具负责执行；不再为每个新任务编写颜色识别、抓放流程或数值逆解程序。本次只有一个场景的失败记录，尚未证明跨物体、跨位置的成功率或安全可靠性。

新实验的完整资料见 [控制链](model_direct_vendor_ik/CONTROL_CHAIN.md) 和 [险情复盘](model_direct_vendor_ik/INCIDENT.md)。当前工作工程的自动执行入口已暂停；归档中的原版控制代码只用于审阅，不可直接重放。旧基线文件保持原样，其文档中的“当前”“后续”均指旧实验当时的状态。
