# 已使能右臂的 ROS 接管入口

`robot_tools/ros_resume_entry.py` 是独立入口；原厂家节点、SDK、健康包装、1%入口和完整计划后端未修改。它只接管 `can1` / USB `1-6.3:1.0` 的已使能右臂，不启动或控制左臂。启动前，原节点必须已到位、停止接收任务目标并正常退出；结束软件不等于物理停止，也不能中断正在发送的一组帧。

启动先核对厂家节点 SHA256、SDK 0.6.2、设备绑定及已有 ROS 总线所有者。`ConnectPort` 强制关闭 SDK 初始化查询，所有发送默认封锁，厂家构造器唯一的 J30 模式请求只记录、不发送。持续收到14种完整真实反馈帧，确认 CAN模式、正常/到位、六电机和夹爪均使能、严格名义关节范围，且至少3秒/20组新反馈稳定后，才设置软件接收命令标志。不会调用使能、闭爪或切换运动模式。

每帧采用 SocketCAN 内核接收时间；年龄和跨片段时间差均限100ms。稳定窗口采用关节0.003rad、XYZ每轴0.5mm、夹爪0.5mm及整体旋转0.003rad边界。姿态比较用与厂家相同的 `Rz(yaw) Ry(pitch) Rx(roll)` 约定，避免欧拉角换支被当成物理旋转。

| 接口 | 输入和行为 |
| --- | --- |
| 私有参数 `~speed_percent` | 整数1–50，默认1；调整参数本身不发CAN。每个回调开始时只读取一次，整组发送固定使用该值。50是厂家速度百分比参数，不是50mm/s或速度/碰撞保证。 |
| `pos_cmd` | 保留厂家 MOVE_P 回调及1mm XYZ量化，始终显式填写当前夹爪目标。正常完整请求为中性0x150、0x151、三帧位姿、0x159夹爪、0x151，共7帧。 |
| `joint_ctrl_single` | 恰好六个有限关节位置，符合厂家名义限位。速度取私有参数，消息中的velocity不覆盖该值；不含夹爪目标。普通J模式加三帧关节，共4帧。launch可映射到`/piper/right/joint_cmd`。 |
| `gripper_srv` | 开口0–55mm，名义effort=0.2、code=1、set_zero=0；原回调的力矩下限被适配器统一改为raw200。仅一帧。 |
| `eval_telemetry` | 原始反馈快照、片段内核时间戳、软件接管/活动/故障状态；旧节点的常规状态和位姿话题继续发布。 |

所有动作共用一把非阻塞锁，覆盖发送前0.3秒稳定、整组精确字节发送、发送后至少0.3秒新反馈稳定。并发请求拒绝，不排队补发；ROS发布方也须逐条发布并等待结果。发送后所有14种反馈都必须晚于整组发送结束；P要求2mm/0.02rad到位，J要求0.003rad到位，控制器必须正常且motion_status=0。最长观察120秒，异常只封锁后续发送，不自动停止、复位、失能或重试。

`command_observed_stable` 表示已观察到所述稳定状态。夹爪服务的`status=true`不证明达到开口、夹住或释放：夹物时实际开口可以大于目标。日志单独提供`jaw_target_m`、`jaw_width_error_m`、`jaw_target_reached`（1.5mm报告公差）及原始开口。释放和抓取必须结合实际开口与图像判断。携物移动时，`pos_cmd.gripper`需保持当前夹持目标，不能沿用空爪开口。

`enable_flag`、enable/stop/reset/go_zero/block服务全部拒绝；没有MIT、示教、自动使能或自动恢复入口。退出只等待当前回调结束并关闭线程/套接字，不发送物理控制。输入模式/目标帧仍非原子，模式切换可能涉及控制器已缓存目标；参数、健康和串行守卫不等于运动路径或停止能力认证。

本轮仅做源码静态审查与AST语法解析；未导入执行本入口、未运行模拟/mock测试、未发硬件或相机命令。新入口须经过独立审查和文件冻结后，才由任务主控执行只读接管。运行时空中允许按已审查单点使用50%，近桌、抓取与入筒采用较低明确参数；每段仍检查当前场景。
