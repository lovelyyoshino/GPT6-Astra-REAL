# L2 有界操作

只加载调用方指定的一个操作契约。在 `projects/piper_right_pick_demo` 下运行：

```bash
PYTHONPATH=src python3 -m right_pick.fast_task_pipeline --composition grip_test
```

契约含 L1 primitives、一次闭环、requirements、evidence 和 max_cycles。原子动作候选由 [L1 运行时](../piper-atomic-runtime/SKILL.md) 的宿主边界处理。接近/旋转/插入使用同一个有限末端动作接口，但接触前提及完成判据不同，不能互换。

- 试抓：闭合后新图，再做经准入的有限试提，核对物体仍随爪且离开支撑；闭爪到位不是抓取。
- 接触段：先核对轴向、支撑、工具通道及宿主实际能力；一次只提一个有限目标，再看物体响应。卡滞、滑移或无进展不靠加力或重复同一目标纠正。
- 释放：确认支撑后松爪、撤离；稳定核验需要两次相隔至少 2 秒的新观测，且物体独立支撑、夹爪已离开。
- 回位：使用本轮不可变参考，分别核对实测和指令关节、完整末端位姿、静止状态；任务成功和回位成功单列。

证据不足时只选择一次有意义的新视角或返回具体 missing fact；达到局部预算即退出。必须保留任务变体：预持不叫自主拾取，手腕旋转不叫螺纹转数，擦拭动作不叫擦除，倾倒不叫全部接收。

通用 L2 契约尚未连接动作执行器；夹笔已有 phase runner 仅作对应投影，不把契约打印命令当物理执行。
