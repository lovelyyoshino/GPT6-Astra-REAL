# L2 有界操作

只加载调用方指定的一个操作契约。在 `projects/piper_right_pick_demo` 下运行：

```bash
PYTHONPATH=src python3 -m right_pick.fast_task_pipeline --composition grip_test
```

契约含 L1 primitives、一次闭环、requirements、evidence 和 max_cycles。原子动作候选由 [L1 运行时](../piper-atomic-runtime/SKILL.md) 的宿主边界处理。接近/旋转/插入使用同一个有限末端动作接口，但接触前提及完成判据不同，不能互换。

- 试抓：按物体当前支撑方式选择验证。普通拾取闭合后用新图和经准入的有限试提核对随动；在座插头、需要固定的插排采用 `grip_supported`，保留原支撑，不套用试提。闭爪到位不是抓取。
- 步长：当前 RGB 显示离目标较远、方向和通道明确时，优先采用本阶段可用的厘米级接近；临近目标按约 5–10 mm 接近，精细对齐缩到约 1–3 mm，最后需要时用约 1 mm 或更小目标；这些是候选步长尺度，不是保证的末端精度，仍取当前姿态下关节与完整过程预算的交集。接触/插入沿用原最多 2 mm 的适用分支并按响应继续缩小。用户举例的“几厘米”受当前入口上限约束，具体见 [图像监督步长选择](../piper-task-pipeline/references/online-readiness.md#图像监督步长选择)。无物体米制距离时按可见间隙与操作阶段选择，不伪造距离；每步新图复核，不预先排队后续动作，也不一开始就全程最小步长。动态暂态与最终到位分开判断，支持分支内的有界短暂偏差记录后继续等待收敛，具体幅度、累计持续时间及异常处理由执行器合同约束。
- 接触段：已授权的抓取、拔插包含必要的轻触和有限微调。具备当前操作的有界执行入口时，直接按“低速小步接触 → 新 RGB 与反馈 → 有限微调”推进；首次接触的成功证据在动作后取得，不要求先证明已经接触或固定才允许建立接触。具体按 [接触与微调](references/bounded-contact.md) 执行；不增加一次“是否允许接触”的请示。
- 遮挡：夹点或物体局部看不清时记视觉 `unknown`，不单独停止或要求人工确认。当前可见通道、本任务已确认方向、健康反馈和完整回执足以支持下一有界目标时直接推进；按 [遮挡与继续动作](../piper-task-pipeline/references/online-readiness.md#遮挡与继续动作) 分开记录动作依据与尚未确认的物体结果。“每步新图复核”不要求每步看清所有夹指、接触点或插脚。
- 释放：确认支撑后松爪、撤离；稳定核验需要两次相隔至少 2 秒的新观测，且物体独立支撑、夹爪已离开。
- 回位：使用本轮不可变参考，分别核对实测和指令关节、完整末端位姿、静止状态；任务成功和回位成功单列。

区分动作前必需信息与动作后才能取得的证据：轴向/通道看不清可取一次有意义的新视角；尚未夹住、尚未接触、尚未插入不是拒绝首次合法尝试的理由。新反馈足以支持下一次局部修正时直接提出一个有限目标；达到局部预算即退出，不另开无限“调试接触”循环。必须保留任务变体：预持不叫自主拾取，手腕旋转不叫螺纹转数，擦拭动作不叫擦除，倾倒不叫全部接收。

通用 L2 契约尚未连接动作执行器；夹笔已有 phase runner 仅作对应投影，不把契约打印命令当物理执行。
